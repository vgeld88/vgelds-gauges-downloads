# Vgelds Gauges — Android Downloads

Official public download and update home for **Vgelds Gauges**, an Android vehicle dashboard and diagnostic app.

## Get the app

The Android APK is **not published yet**. When the first signed release is ready, download it from [Releases](https://github.com/vgeld88/vgelds-gauges-downloads/releases/latest).

## Updates

Inside the app, open **Settings → App updates** to check for a newer released version. Android may ask you to approve installation of APKs from your browser or file manager.

**Important:** Only install files from this official repository. No Android source code, private credentials, or APK signing keys belong in this public repository.

## Notes

Features and supported vehicles depend on the installed app version and OBD adapter. Follow safe-driving practices; do not interact with gauges while driving.
